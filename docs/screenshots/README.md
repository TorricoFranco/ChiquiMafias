# Capturas

Imágenes que usa el [README principal](../../README.md). Mientras no existan, los
bloques que las muestran están comentados (`<!-- … -->`) para que no aparezcan
imágenes rotas. Al agregar una captura, descomentá su bloque en el README.

| Archivo | Qué mostrar | Dónde se usa |
|---|---|---|
| `home.png` | Home con partidos en vivo, tabla y chat | Captura principal |
| `partido-en-vivo.png` | Detalle de un partido: marcador, eventos y formaciones | Galería |
| `apuestas.png` | Mercados de apuestas con el pozo y las cuotas | Galería |
| `chat.png` | Chat de un partido con stickers y un mensaje fijado | Galería |
| `tienda.png` | Tienda de cosméticos | Galería |
| `perfil.png` | Perfil con banner, color de nombre y racha | Galería |
| `discord.png` | Hilo de un ticket o alerta de reporte en Discord | Galería |

Recomendaciones:

- PNG a 1280×720 (o un GIF de menos de 5 MB para la captura principal), en el tema
  oscuro de la app.
- Usá datos de prueba: sin emails ni nombres reales de usuarios.
- Para las capturas de mobile, 390×844 y de a dos por fila.
